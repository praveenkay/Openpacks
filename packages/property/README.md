# Property Pack (Free)

**Base:** [OpenProperty](https://github.com/clawnify/OpenProperty) (MIT)

Units, tenants, leases, rent ledger, maintenance work orders.

## Install (few clicks)

```bash
chmod +x install.sh
./install.sh "Your Company Name"
```

Or clone and run yourself:

```bash
git clone https://github.com/clawnify/OpenProperty.git
cd OpenProperty
pnpm install
pnpm dev
```

Open http://localhost:5173. Sample data appears on first run.

## What you get
- Properties & units
- Tenants & leases
- Monthly rent ledger
- Maintenance work orders
- Dashboard (occupancy, collected, outstanding)
