# General SMB Pack (Free)

**Base:** Dolibarr (Docker)

Invoicing, CRM, inventory, projects, accounting for any small business.

## Install

```bash
chmod +x install.sh
./install.sh "My Business" 8081
```

Open http://localhost:8081 — login `admin` / `admin`.

## What you get
- Customers & invoices
- Products / services
- Projects
- Basic accounting
- Reports
