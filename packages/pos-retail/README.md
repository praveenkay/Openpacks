# POS / Retail / Vendor Pack (Free)

**Base:** Dolibarr (Docker) — practical free ERP + POS  
**Alternatives:** Posnic (AGPL, offline-first), MyCompany (Apache)

Shops, food trucks, market stalls, small vendors.

## Install (Docker)

```bash
chmod +x install.sh
./install.sh "My Shop" 8080
```

Then open http://localhost:8080 and log in with `admin` / `admin`.

## What you get
- Product catalog
- Checkout / POS
- Inventory
- Invoices
- Customers
- Basic reports
